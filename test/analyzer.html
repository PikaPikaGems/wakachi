Load dictionary analyzer.load()
The first time, downloads the dictionary (45 MB) and saves it on this device; after that, reads it from the device (no download). Then starts Sudachi, which uses about 135 MB of memory while loaded.
Unload analyzer.unload()
Frees that memory now. The files stay saved, so the next analysis reloads them in under a second, without downloading. wakachi also does this by itself after a minute without use, and when the page goes to the background.
Delete files from device analyzer.clearCache()
Removes the saved files (45 MB) from this browser's storage; the next load downloads them again. A loaded Sudachi keeps working until it's unloaded. Apps rarely need this (e.g. a "free up storage" button).
